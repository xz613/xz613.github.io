> 机器学习课堂笔记：

## 一、机器学习概论：

### 机器学习是什么？

机器学习就是让机器能自动找到一个函式 (function)

- **语音识别（Speech Recognition）：** 输入的音频，输出的式音频对应的文字。
- **图片分类：** 输入的式图片，输出的是类别（比如 猫，狗）
- **AlphaGo 下围棋：** 输入是的当前棋盘的状态，输出是下一步落棋的位置。

### 机器学习的三个步骤

- 写出一个函式 function
- 定义一个 lost 的function
- 截一个 optimization problem 找到 w*, b* 让loss 最小

以上三个步骤合起来叫做训练，也可以理解为：

（1）、确定模型（Model）/ 函数集 （Function Set）  
（2）、确定如何评价函数的好坏  
（3）、确定如何找到最后的函数

### 1、机器学习：机器可以找到哪些函数？

- **（回归）Regression：** 机器学习的输出是一个数值。比如 pm2.5的预测
- **（分类）Classification：** 给机器多个选项，机器选择的输出是其中的一个选项。比如 yes or no
- **（结构化学习）Structured Learning：** 不仅是输出一个数值，不仅是一个选项。而是输出一个结构性的数据。比如文档，图片...

> **注：Model：**  y = b + wx1
>
> **注：模型：** 一个带有未知 parameter 的 function

### 2、机器学习：如何告诉机器我们希望找到什么函数？

我们该如何为机器学习提供学习资料？

- **监督学习（Supervised learning）**  
  可以把有监督学习中的 "监督" 理解为 "标签（Label）",  即数据集不仅包括特征，还  包括标签。 有了标签我们就可以评价一个函数的好坏，进而来优化这个函数。使用 loss  来判断函数的好坏，loss 越小，函数越好。

- **强化学习（Reinfocement learning）**  
  原来的AlpahGo 是通过有监督学习优化到一定程度，然后用强化学习继续优化。  
  新版本的AlphaGo 是完全通过强化学习实现的，优于原来的 AlphaGo。

- **无监督学习（Unsupervised Learning）**  
  只给机器提供数据特征，但不提供数据标签。

- **有监督学习（以围棋为例）**  
  函数的输入（数据特征）就是棋盘状态，函数的输出（数据标签）就是下一步落棋的位置。  
  此时，我们需要为机器提供的数据就类似棋谱（如果现在棋局是这样，那下一步怎么落棋最好），但其实人类不一定知道怎么落棋最好。  
  **个人想法：** 理论上，通过这样的有监督学习，机器是无法超越人类的。因为这样的有监督学习的本质是人类把自己的下棋策略教给机器，机器学习的内容仅仅是人类的下棋策略而无法“自主进行思考”，所以理论上机器是无法超越人类的。同时要注意，这里的人类指全人类。

- **强化学习（以围棋为例）**  
  让机器跟自己、别人下棋，把结果（赢或输）作为 Reward，引导机器学习如何下棋。如果它赢了，那它就知道这一盘里有几步棋下得好，但不知道是哪几步；如果它输了，它就知道这一盘里有几步棋下得不好，但不知道是哪几步。  
  **个人想法：** 理论上，通过这样的强化学习，机器是可以超过人类的。因为两者的学习材料没有本质区别，但机器的机能却优于人类，这里讲的机能包括信息共享能力、记忆能力、执行能力等方面。

### 2.1 线性回归模型

**线性回归模型应用案例：(Regression Cases)**

- **股票市场预测** — 预测某个公司的股票情况
- **自动驾驶车** — 预测方向盘的转动角度
- **推荐系统** — 预测某用户购买某商品的可能性

**线性回归模型 (Linear Regression Module)**

如：

```
y = f(x) = w * x + b
```

- **y** 是输出
- **ŷ** 是真实值/标签（lable）
- **w** 是权重
- **b** 是偏置 (bias)
- **X** 是输入，也可以叫做特征

数据集中一般包含多个 object （对象/样本），每个object 一般包含多个 component（分量/特征）。上标是 object 的索引，下标是component 的索引。

**损失函数：**

如果不考虑模型的好坏，衡量一个函数的好坏，其实就是衡量模型参数的好坏。以线性  模型为例，就是衡量参数和的好坏。如

- **输入：** 一个函数

#### 梯度下降（Gradient Descent）

梯度下降可以优化损失函数的值，使其尽量小，即可能找到最好（在数据集上拟合效果最好）的模型参数。

现在假设模型f 中只有一个参数 w，则损失函数 L(f) = L(w), 梯度下降算法如下（若模型有多个参数，按相同方法更新参数）

1. **初始化参数**  
   随机取一个参数 w0 （并不一定是随机取），让 w = w0

2. **计算梯度**  
![梯度公式](/img/机器学习-笔记/梯度.png)
   如果小于0，此时w 增大则L(f) 会减小; 如果大于0，此时如果大于0，此时ω减小则 L(w）会减小。如果模型有多个参数，则计算损失函数在各个参数方向上的偏导数。

3. **更新模型参数**  
   ![梯度公式](/img/机器学习-笔记/跟新模型参数.png)
   w 的变化量取决于梯度和学习率（Learning Rate）的大小：梯度绝对值或学习率越大，则w变化量越大。  
   如果模型有多个参数，则用上一步计算出的偏导数对应更新各参数。

4. **重复第2步和第3步**  
   经过多次参数更新/迭代（iteration），可以使损失函数的值达到局部最小（即局部最优， Local Optimal），但不一定是全局最优。

### 2.2 如何选择模型，减小误差

**模型选择（ How to select module）**

- **模型越复杂，一般在训练集上的误差 （Error）越小**  
  因为更复杂的模型（函数集）包含了更多的函数，比如二次模型包含了线性（一次）模  型。

- **模型复杂，其在测试集上的误差（Error）不一顶越小。**  
  因为模型在过于复杂时，越容易被数据影响，可能导致过拟合。

#### 误差

**误差的来源**

暂时称通过机器学习得到的函数称为人工函数，它其实是对 "上帝函数"的估计（Estimator）,和"上帝函数"之间是有误差的。

误差来源于两方面：一是 Bias， 二是Variance，需要权衡 （trad-off）两者已使总误差最小。

![误差示意图](/img/误差.png)

**Variance：**

- **定义**  
  使用相同模型在不同数据上拟合得到的函数是不同的，这些函数之间的离散程度就是Variance.

- 以射箭为例，Variance衡量的就是射得稳不稳。

- 模型越复杂，Variance越大。

- 因为模型越简单，越不容易被数据影响（对数据不敏感，感知数据变化的能力较差），那Variance就越小。

**Bias**

- **定义**  
  使用相同模型在不同数据上拟合得到的函数是不同的，取这些函数的"期望"，该期望与"真理"的差距就是Bias。

- 以射箭为例，Bias衡量的就是射得准不准（这里的"准"的含义有待商榷）。

- 模型越简单，Bias越大。

- 因为模型就是个函数集(Function Set）。模型越简单，则其包含的函数就越少、包含"上帝函数"的几率就越小，甚至可能不包括上帝函数。  
  在函数集很小的情况下，即使是其中最好的函数，它与"上帝函数"的差距也还是很大的。

### 2.3 欠拟合和过拟合

#### 欠拟合：（Underfitting）

- **定义：** Bias 较大. Variance 较小
- 如果模型在训练集上的误差很大，则此时 Bias 是最大的，情况为欠拟合。

**Bias 大时如何处理？**

- 使用更复杂的模型，比如添加考虑更多维度的输入，把线性模型换成非线性模型。

#### 过拟合（Overfitting）

- **定义：** Bias 较小，Variance 较大。
- 如果模型在训练集上的误差很小，但是在测试集上的误差很大，此时Variance sh ishi是大的，情况为过拟合。

**Variance 大时如何处理？**

- 使用更复杂的数据集（很有效，但不一做的到）数据曾强等方法。
- 使用更简单的模型（不是根本方法）  
  可能是模型过于复杂导致了过拟合，因此可以简化模型缓解过拟合。
- **正则化（Regularization）**  
  正则化可能使 Bias 增大，所以需要调整正则化的参数。

#### 平滑（Smooth）

- **定义**  
  平滑是指输入变化速度影响输出变化速度的程度（输出对输入的敏感程度）。  
  假设输入变化，如果函数越不平滑，则输出变化程度越大。  
  函数参数越接近0，这个函数就越平滑。

**我们为什么喜欢一个平滑的函数？**

适度平滑的函数可以缓解函数输入中包含的噪声对函数输出的影响。  
如果输入中包含一些噪声/干扰（noise），那平滑函数的输出受输入中包含的噪声干扰的程度更小

**我们为什么不喜欢过于平滑的函数？**

函数过于平滑，就无法有效地提取数据的特征，这不是我们想要的函数。  
假设有一个极限平滑的函数，即该函数的输出不受输入的影响，那当然不是一个好的函数。

### 2.4交叉验证

**交叉验证（Cross Validation）**

在机器学习中，通常不能将全部数据用于模型训练，否则将没有数据集可以用来评估模型。

#### The Validation Set Approach

- **定义**  
  将数据集划分成 训练集（Training Set）和 测试集（Test Set）两部分。

- **缺点**  
  这种方法的缺点是依赖于训练集和测试集的直接划分方法，并且只用了部分数据进行了  模型的训练。

#### LOOCV (Leave One Out Cross Validation)

- **定义**  
  假设数据集里面有 n 个数据，取其中1个数据作为测试集，将剩下的 n-1个数据作为  训练集，这样重复n次就得到n个误差值，最终使用这n 个误差值的平均值评估该模  型。

- **优点**  
  该方法不受训练集和测试集划分方法的影响，因为每个数据都单独做过测试集；同时该  方法用了 n-1 个数据训练模型，也几乎用到了所有的数据，保证了模型的Bias 更小。

- **缺点**  
  该方法的缺点是计算量过大，是 The Validation Set Approach 耗时的n-1倍。

#### K 折交叉验证（k-fold Cross Validation）

- **定义**  
  该方法是 LOOCV 的折中，将数据集拆成k 份。

- **如何选取k的值**  
  k的值是一个Bias 和 Variance 的trade-off。一般选择 k = 5 或10。  
  K 越大，每次训练时训练集的数据量就越大，则 Bias 越小；但每次训练时的训练集之间的相关性越大（考虑极端的情况 k = n，也就是LOOCV, 每次训练使用的数据几乎是一样的），这种大相关性会导致最终的误差具有更大的 Varience。

#### 梯度下降伪代码

梯度下降可以优化损失函数的值，使其尽量小，即可能找到最好（在数据集上拟合效果最好）的模型参数。

现在假设模型f 中只有一个参数 w，则损失函数 L(f) = L(w), 梯度下降算法如下（若模型有多个参数，按相同方法更新参数）

1. **初始化参数**  
   随机取一个参数 w0 （并不一定是随机取），让 w = w0

2. **计算梯度**  
   ![梯度公式](/img/机器学习-笔记/梯度.png)
   如果小于0，此时w 增大则L(f) 会减小; 如果大于0，此时如果大于0，此时ω减小则 L(w）会减小。如果模型有多个参数，则计算损失函数在各个参数方向上的偏导数。

3. **更新模型参数**  
    ![梯度公式](/img/机器学习-笔记/跟新模型参数.png)
   w 的变化量取决于梯度和学习率（Learning Rate）的大小：梯度绝对值或学习率越大，则w变化量越大。  
   如果模型有多个参数，则用上一步计算出的偏导数对应更新各参数。

4. **重复第2步和第3步**  
   经过多次参数更新/迭代（iteration），可以使损失函数的值达到局部最小（即局部最优， Local Optimal），但不一定是全局最优。

#### 自适应学习率（Adaptive Learning Rate）

梯度下降过程中，固定学习率并不合理。学习率太大，可能导致 loss 不减小反而增大；学习率太小，loss 会减小得很慢。基本原则是随着参数迭代更新，学习率应该越来越小，比如
![学习率](/img/机器学习-笔记/自定学习率.png)

有更好的方法，每个参数都有自己的学习率。比如 Adagrad。

#### Adagrad

**Adaptive Gradient Descent**,自适应梯度下降。2011年提出，核心是每个参数（parameter）有不同的学习率。

- **定义**  
  每次迭代中，学习率要除以它对应参数的之前的均方根（RMS）。  
  即 ![学习率除均方根](/img/机器学习-笔记/学习率除均方根.png)，其中t是迭代次数，ω是参数，g是梯度，η是初始学习率。  
  随着参数迭代，t越来越大，![均方根](/img/机器学习-笔记/根号.png)也越来越大，因此学习率的变化趋势是越来越小。

#### SGD

**Stochastic Gradient Descent**，随机梯度下降，1847年提出，可以让训练过程更快。普通梯度下降中需要计算所有样本的 Loss, 而SGD 只计算一个样本的 Loss，然后进行梯度下价格。

#### 梯度下降的数学理论

参考视频：https://www.bilibili.com/video/BV1JE411g7XF/?p=5&vd_source=e646be2971ba0b65b5e32845717a81fb  从42分27秒开始看，老师讲的很好。

1. 初始化一组参数后，我们找到邻域中另一个损失函数值最小的一组参数并更新参数 （然后不断重复这一步骤）。
2. 在极小的领域中，可以利用泰勒级数将损失函数简化，然后求其最小值，损失函数简化后，要使器最小是让其中两个向量的内积最小，由此可以得出新的一组参数得值（具体过程略），这就是梯度下降。
3. 学习率的作用是限制邻域大小，学习率太大可能使得太大，导致损失函数展开成泰勒级数时的误差较大。
4. 当然也可以将损失函数展开成2次，但是这并不实用，因为要计算二次微分，甚至可能要求出海森矩阵，逆矩阵等等，这些在做深度学习时是不够用的。

#### 梯度下降的局限性

梯度下降过程中，每次参数更新不一定都会使损失函数的值更小。

求出的只是局部最小值（Local Miniima） 甚至是鞍点（Saddle Point），不一定是全局最优解。

## 四．Classification

### 4.1、分类简介及其与回归的区别

**分类模型应用案例（Classification Cases）**

- **信用评分（credit Scoring）**
  - 输入：收入、储蓄、职业、年龄、信用历史等等
  - 输出：是否贷款

- **医疗诊断（Medical Diagnosis）**
  - 输入：现在症状、年龄、性别、病史
  - 输出：那种疾病

- **手写文字识别（Handwritten Character Recognition）**
  - 输入：面部图片
  - 输出：是那个人

- **人脸识别（Face Recognition）**
  - 输入：面部图片
  - 输出：是那个人

#### 把分类当成回归去做？

不行。

- 假设有两个类别，其中类别1的标签为1，类别2的标签为-1，那0就是分界线，大于0就是回归1，小与0就是类别2.  
  "回归模型" 会惩罚那些太正确的样本。如果结果远远大于1，他的分类应该是类别1还是类别2？这时为了降低整体误差，需要调整已经找到的回归函数，就会导致结果的不准确。
  ![类型区别](/img/机器学习-笔记/类别区分.png)

- 假设有多个类别，类别1的标签是1，类别2的标签是2，类别3的标签是3.这样的，标签间具有2和3相近，3大于2这种本来不存在的数字关系。

#### 理想替代方案（Ideal Alternatives）

- **模型** — 模型可以根据特征判断类型，输入是特征，输出是类别
- **损失函数** — 预测错误的次数，即![预测错误的次数](/img/机器学习-笔记/预测错误次数.png)

## 好记性不如烂笔头：

双分支：模型

训练集，验证集，测试集：训练集 —— "平时的作业与练习"，模型会反复"看"这些数据，是唯一直接参与学习的数据集。  
验证集 —— "模拟考试"，模型不直接从中学习，但你的决策会依赖它。所以他会间接的影响最终模型。  
测试集 —— "最终的高考"，绝对不能被模型学习，甚至最好不要提前分析它。直到所有的训练和调参完成，才拿出来用一次。如果用测试集的结果去修改模型，测试集合就退化成了验证集，你就会高估模型的真实水平。

过拟合：模型在训练数据上的误差（训练误差）极低，但在从未见多的新数据上的误差（泛化误差）很高。模型的复杂度超过来问题本身的复杂度。

Bias： 模型预测值与真实值之间的差异，它反应的是模型的拟合能力。  
通俗的说：如果你的箭总是射中靶心的同一个位置，但偏离靶心很远，这就是高偏差。  
欠拟合。

Variance：方差，方差衡量的是模型在不同训练集上寻来出来的结果的波动程度。他反应的  是模型的稳定性。  
 同属的来说：如果你的箭每次射中的位置散布的非常开，虽然有时候能蒙中靶心但大部分时候，都射的很偏，这就是高反差。  
过拟合。
